# 0.8.0

- Save sourced decisions, constraints and blockers with supporting file references.
- Check saved decisions against changed or missing evidence.
- Retrieve relevant context with citations and a token budget.
- Keep memory separate across repositories, worktrees, branches and sessions.
- Resume saved sessions and explicitly share selected records.
- Track review findings, fixes, verification outcomes and failed approaches.
- Export session memory to Markdown or Obsidian.
- Improved concurrent-session handling, memory writes, file paths and credential redaction.

Install from GitHub:

```bash
pip install "git+https://github.com/atharvavdeo/agent-mem.git@v0.8.0"
```
